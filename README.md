 


# 🎬 Ticket Booking Data Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing movie ticket booking data using **Microsoft Excel and Power BI**. The objective is to clean and organize booking records, analyze booking trends, and create an interactive dashboard to gain insights into booking performance.


## 🛠️ Tools & Technologies
- **Microsoft Excel** – Data cleaning, duplicate removal, and formula-based analysis
- **Power BI** – Interactive dashboard development and data visualization
- **Excel Formulas** – IF and XLOOKUP for categorization and data integration

## 🔍 Project Workflow

### 1. Data Cleaning & Preparation
- Cleaned and organized the movie booking dataset in Excel.
- Identified and removed duplicate booking records.
- Prepared the data for accurate analysis and visualization.

### 2. Data Transformation
- Used the `IF` formula to derive categories from booking data.
- Applied `XLOOKUP` to connect booking records with movie details.
- Structured the data for meaningful analysis.

### 3. Dashboard Development
- Created an interactive Power BI dashboard.
- Designed KPI cards to highlight key booking metrics.
- Used charts and slicers to explore booking performance.
- Enabled filtering and comparison across different booking dimensions.

### 4. Exploratory Data Analysis
Analyzed booking performance based on:
- City
- Age Group
- Payment Method
- Movie
- Theater
- Ticket Price
- Movie Rating
- Weekday vs. Weekend Bookings

## 📊 Key Insights
- Weekday bookings were higher than weekend bookings in the analyzed dataset.
- Booking activity varied across different cities.
- Customer payment preferences differed across payment methods.
- The dashboard enabled comparisons of booking performance across movies, theaters, age groups, and ticket prices.

*Note: These findings are based on the analyzed dataset and may not represent general movie booking trends.*

## 🎯 Project Objectives
- Improve data quality through cleaning and duplicate removal.
